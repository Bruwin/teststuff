## Surprises / notes for the next session

- The biggest risk is not architecture, it is *context*: a 300-line file is cheap
  to re-read, a 3 000-line file is not. Hence the size rules in `LAY-06`.
- "No mistakes" is unachievable as a promise but achievable as a process: the
  golden-hash matrix plus `verify.sh` turns most defects into a red light within
  minutes rather than weeks. Stated in `PLAN.md` §0 so nobody is misled.
- Physics determinism is a trap. Resolved by making physics a fidelity layer
  (`D-004`) rather than authoritative state — this is the decision that keeps
  saves portable and co-op feasible.
