## Findings the gates caught (all fixed in-session)

1. **Clock drift, real bug.** `clock_ += 1/30 s` in Q16.16 truncates to 2184
   ticks-units per step; after 30 ticks the clock read 0.999 s. Fixed by deriving
   time from the tick counter (`tick * 65536 / 30`), which is exact. The unit test
   `world_clock_advances_one_tick_at_a_time` is the regression guard.
2. **Linter false negative:** include paths are string literals, so scanning
   comment- and string-stripped text found no `#include "render/..."`. Fixed by
   scanning a comments-only-stripped copy for includes.
3. **Linter false negative:** TODO checks ran on comment-stripped text, so a bare
   `// TODO:` could never be reported. Fixed by scanning raw lines.
4. Non-ASCII punctuation and four over-length macro lines in `core/` — fixed.
5. `LOG-01` was firing on test files; scoped to `src/` (tests may print).
